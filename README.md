# StudentSpace

A responsive React application to manage favourite students.

## Features

- Login and signup using localStorage
- View a list of students
- Add and remove favourite students
- Prevent duplicate favourites
- Store favourites separately for each user
- Preserve favourites after refreshing
- Navigate between pages without reloading
- Responsive design using Tailwind CSS

## Tech Stack

- React
- Vite
- JavaScript
- React Router
- Context API (`useContext`)
- React Hooks (`useState`, `useEffect`)
- Tailwind CSS v4
- localStorage

## Run Locally

```bash
npm install
npm run dev
```

## Note

This project uses frontend-only demo authentication with localStorage. It is intended for learning and does not provide secure authentication.
